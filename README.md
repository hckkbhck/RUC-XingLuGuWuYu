# RUC物语

在中国人民大学中关村与通州校区的秋日像素地图里散步，探访地点并把体验记进漫游手册。教室安排、食堂菜单和社团活动为游戏内模拟资料。

## 启动

- 首页、原迎新链接和离线版共用一张连续地图。首次进入在中关村求是广场的喷泉旁注册。从广场东侧沿路向南，在路口向东可到东门。再向东穿过窄草地就能走上通州的宝塔山路。按 M 可选择任一校区的地点并规划步行路线。
- 玩家资料通过当前浏览器的 localStorage 保存，本地玩家 ID 仅用于本机资料标识。清除站点存储或更换浏览器后，需要重新登记。
- 双击 `dist/RUC物语.html` 可离线游玩，图片、声音与游戏代码均已内嵌。已有离线存档的玩家可继续从原路径打开 `RUC-Campus-Walk.html` 或 `RUC-Campus-Welcome.html`。
- 开发时运行 `npm run dev`，打开 http://127.0.0.1:4173/。
- 运行 `npm run build` 生成 `dist/site/` 与离线 HTML。将 `dist/site/` 内的文件完整发布到静态站点，保留子目录结构。Cloudflare Pages 的框架预设选 None，构建命令填 `npm run build`，输出目录填 `dist/site`。
- 运行 `npm run preview`，在 http://127.0.0.1:4174/ 打开网页版。本机服务运行时可访问此地址，旧入口 `/campus/` 也可使用。
- 宝塔山路横贯通州西门与东门。到通州东门南侧候车亭按 E，选择「查看站牌」可乘车去中关村东门公交站。中关村东门公交站也可搭乘返程车。

构建需要 Node.js 和 npm，可直接运行，无需安装项目依赖。旧接口回归测试使用 Node.js 22.13 或以上版本的内置 SQLite。游戏中的花园、评价、任务与个人拾光均由浏览器保存。

### 校园拾光涂鸦墙

走到求是广场喷泉池边，或在中区食堂、立德楼门口打开地点菜单，选择「查看校园拾光」。每处有两张带故事的预设照片。点「留下我的痕迹」，选择照片并填写昵称和文字，发布后会排在该地点墙面的第一张。同一次游玩中可以离开再回来查看，刷新页面会恢复预设内容。

### 求是广场的校园任务栏

走到求是广场喷泉北侧最左边的展板前，按 **E**、点互动提示或点展板打开任务栏。点「新建任务」填写要办的事，可附地点。在同一浏览器里可以开始、添加个人备注、放回待办、完成或撤回，重新打开即可继续。

### 中区食堂的图文评价

在食堂门口按 **E**，从羊皮纸首页进入「每日菜谱」，点菜名可以查看介绍和同学评价。每条评价可写 500 字，附一张 JPG、PNG 或 WebP 实拍（最大 8 MB），也可以只发照片。点已发表的缩略图可以看大图。

网页与离线版均展示内置菜品评价，新增的文字与实拍保存在本机 IndexedDB。旧版 localStorage 中的个人评价仍可查看。

### 种一朵你的花

按 **M** 标记「崇德花园」，走到崇德楼正北、中区食堂东侧的草坪。按 **E** 或点花格，选一个空位和花种，确认后花就会出现在原地。选中自己的花，可以点「更换花种」在原位换花，也可以点「铲掉这朵花」并确认，再到空格重新种。本机花园共有 80 个花位，每份本地玩家资料可种一朵花。旧花朵沿用原有 IndexedDB 存档。

### 校园拾光

地图自带六则演示拾光。广场西侧的三则故事聚在同一个气泡中，照片展板收录中关村三张、通州一张演示照片。

在可行走的位置按 **P** 或点底部「拾光栏」，可留下 500 字以内的文字和一张照片（JPG、PNG 或 WebP，最多 8 MB），两者至少一项。回到原处按 **E** 或点气泡即可重读。求是广场喷泉北侧有一排展板，走到中间的照片展板前，可以按校区翻看演示和本机照片。拾光保存在当前浏览器的 IndexedDB 中，同一入口刷新或重开即可恢复。清除站点数据会清除个人记录，演示拾光仍可阅读。

运行 `npm test` 可检查地图入口连通、建筑移动后的贴图与碰撞、导览路线、本地存档与音频恢复。地点原点、相对入口、触发半径和轮廓位于 `game/layout.js`，教室、菜单与地点活动文案位于 `game/content.js`。游戏资源来源记录在 `assets/SOURCES.md`。

## 一条演示路线

1. 从求是广场出发，往东南可到东门，或打开地图标记一勺池。使用方向键或 WASD 行走，触屏可用方向按钮。出现互动提示后按 E 或点击提示。
2. 在一勺池打开「拍照打卡」，拍摄游戏画面，或选择一张本机图片，照片会直接收入漫游手册。
3. 按 M 打开校园导览，选田径场为目的地，沿路线去试跑，再去中区食堂查看当日菜单。
4. 在藏书馆收藏书目，到教二草坪敲一段风铃或坐下看猫追叶。按 J 打开「漫游手册」回看沿途记录。

漫游手册的照片和记录保存在当前浏览器的本地存储中。同一台设备上，离线文件与网页各自拥有存档。
