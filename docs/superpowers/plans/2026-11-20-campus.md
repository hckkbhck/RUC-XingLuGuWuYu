# RUC物语 · 中关村东门片区实施计划

> 执行采用 subagent-driven-development。以下清单记录交付与验证。

**目标**　玩家打开网页即可在新平面图对应的校园步行、体验地点事件、留下本地足迹并再次游览。

**架构**　Canvas 2D 绘制像素世界；ES 模块分别管理布局、场景、地点内容、音频和界面。网页与可双击的离线版共用入口。

**技术栈**　原生浏览器 API、JavaScript、CSS、Node.js。

**需求**　仓库根目录 RUC-Campus-PRD.md v0.7，本轮用户已确认仅做中关村片区。底图采用 RUC-Campus-Building-Locator.png 与 .ruc-image-reference/latest-campus-layout.png。

## 全局约束

- 仅按新图选择地标与楼群，建筑独立配置。取消跨校区线路。旧 MVP 不参与设计。
- 校园资料采用中文，模拟校务数据标明来源类型，照片和足迹保存在本机。
- 所有地图入口可步行抵达；全屏、键盘、触控和无音频环境均可继续游戏。

## Review Focus

- 从出生点检查每个入口的可达性；红楼三栋独立标识。
- 模态窗口打开、键盘失焦或触控取消时，角色立即停止。
- 图片损坏、取消、存储超限和刷新重访保留原记录，可重试。
- 小地图与主地图读取同一份布局，目的地和角色位置一致。
- 缩窄游戏窗口后，角色、交互入口与关闭按钮仍可操作。

### Task 1 — 地图、场景美术与步行

**文件**　新增 game/layout.js、game/world.js，可新增 game/ 下的美术模块和 assets/game/ 下小型清理后的贴图；验证 tests/layout.test.mjs。

- [x] 从新版定位图复刻地物方位、形状、道路、绿地与相对尺度。排除编辑器中最终图已删除的楼。坐标采用原图 1908 × 824。导出 WIDTH、HEIGHT、places、roads、spawn；roads 为 {x,y,w,h}[]，places 为 {id,name,kind,x,y,entry:{x,y},...}[]；x/y 是模块原点，entry 是相对原点的可通行入口，导出 entrance(place) 返回绝对坐标。按需增加 shape 或 bounds；导出 drawAtlas(ctx,width,height) 画同源缩略地图底图（无需标签、角色、目的地，接口消费方绘制）。
- [x] 稳定 ID 为 pond、field、gym、student、science、canteen、art、library、chongde、red-north、red-middle、red-south、humanities、lawn、qiushi、gate。地点名按图。默认出生点在一勺池附近的开放道路，首屏能见到池塘、校园建筑、人物和周边环境，场景有自然细节。优先使用项目现有池塘、树、行走角色、长椅素材。建筑、图上田径场和草坪清晰可辨。用统一像素密度、有立面与窗的近俯视校园建筑和局部名称牌，避免蓝图色块。
- [x] 导出 createWorld(canvas,{onUpdate,onInteract,onStep,onRange})，返回 {setPaused(bool),setMove(x,y),setDestination(id|null),setZoom(number),setAction(name|null),getState(),destroy()}。onUpdate(state) 的 state 包含 x,y,near(地点对象或 null),moving；onRange(place|null)，onInteract(place)，onStep()。键盘 WASD/方向键与 E，触控方向由 setMove 驱动，斜走归一，停止归静止帧，人物头顶显示感叹号，目的地方向指示。setAction 支持 sit、cat、music、photo 的可见场景反馈。世界内部可视范围响应容器变化。
- [x] 用 node --test tests/layout.test.mjs 验证 16 地点、落点、全入口可达及碰撞；必要时导出 canWalk(x,y)。美术资源通过相对 HTML 入口的路径载入（URL 字符串使用 assets/...），构建将使用相同路径打包。

### Task 2 — 地点玩法与本地记录

**文件**　game/events.js、game/records.js、tests/records.test.mjs。入口 openPlace(place)，注入 panel、record、onSceneAction、onToast。事件配置按地点 ID 分派，记录按地点与事件分别索引。

- [x] 一勺池提供文件预览、取消、确认、结果时间与上次照片；解码失败和本地保存失败可恢复。测试刷新、取消和写入异常。
- [x] 中区食堂提供日期菜谱与分区拥挤热图；理工楼、崇德楼、求是楼与人文楼按 ID 显示不同教室和课表。其他入选建筑分别提供符合其位置的可操作活动与结果。
- [x] 教二草坪串联长椅、乐器、校园猫系统事件预告与回放、拍照及个人记录。玩家能退出和重玩；手册汇总个人足迹与照片。

### Task 3 — 界面、集成、音频与发布

**文件**　index.html、game/app.js、game/ui.css、game/audio.js、game/audio-config.js、tools/build.mjs。

- [x] 游戏直接进入地图，提供轻量 HUD、右上同源小地图、地图目的地、手册、声音设置、全屏、帮助与触控。模态窗口支持返回、关闭和键盘焦点恢复。
- [x] 独立 AudioManager/config 处理脚步、进入范围、按钮、打开关闭与事件反馈，资源失败与静音不影响行走。保存音量偏好。
- [x] 构建纯静态站点与可双击的离线文件，支持子目录路径。用浏览器走完整条演示路线，检查窄屏、全屏、照片刷新和取消。至少两轮基于截图调整画面。

## 演示路线

一勺池拍照 → 田径场或学生活动中心 → 中区食堂查看菜单 → 藏书馆收藏 → 教二草坪演奏、观猫与拍照 → 在手册回看。
